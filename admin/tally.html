How scoring and syncing work

Games added, renamed or removed in Mission Control and the Planner appear automatically. Team changes also refresh automatically. Each game is scored separately for each team, with an overall total. Renamed Mission Control game slots and recognized Planner game renames keep their scores. Removed games are hidden rather than immediately deleting historical points; if a game returns, its saved points may be restored. Open the Planner or Mission Control to edit game names, not this score sheet.

Updates are checked regularly while this page is open, and whenever you return to it. Every score change saves to the shared Cloudflare database. If another organizer updates a score at the same time, you’ll see a conflict warning and the newest data will be reloaded.
